LeadAgent: Agent with human approval

  • Python
  • FastAPI
  • Agent pipeline
  • Human-in-the-loop

Reads a business website, extracts facts, scores fit on a transparent 100-point rubric, drafts a pitch and then stops until a person approves, edits or rejects it. Nothing is sent automatically. Rule-based by default, optional LLM. Shown on 6 fictional sample sites, with 19 automated tests.

11

Delta: Personal PC assistant

  • Python
  • FastAPI
  • Tool calling
  • Safety model

A local assistant for a Windows PC: apps, volume, files, reminders, notes and more, by typing or voice. Every action passes one gate that decides safe, ask first or blocked, keeps an audit log and keeps file access inside chosen folders. Runs on a free hosted open-weight model (or fully offline with rules). The dashboard shows live vitals, tasks, activity and safety state next to the chat, and a Vibe Coding space lets you describe an app in plain English, review the code changes as diffs, preview it live and undo with git. Self-test passes on a real Windows PC; the dashboard screenshot uses simulated demo values (693 automated tests passing).
